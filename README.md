# dm_lab
Лабораторная работа по дискретной математике


Составить ДКА на языке Python или C для распознования некоторого паттерна в тексте. Для этого необходимо реализовать его графическое представление и алгоритм, который работает согласовано с этим представлением. Покрыть тестами, рассмотреть различные случаи и возможности такого ДКА.					
					
Вариант 2

Входная информация:
"Событие произошло 2 декабря 1934 года.
Ничего не произошло 3.01.2025."

Ожидаемый выход:
[[2, декабря, 1934], [3,01,2025]]

Описание:
Даны даты событий в массиве текста. Их необходимо достать из текста
